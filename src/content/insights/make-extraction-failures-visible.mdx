An extracted value is easier to review when its source is visible beside it. In [Tenancy](/work/tenancy), that means showing lease details with the source pages and giving the reviewer a way to approve, correct or reject flagged fields.

I would use the same approach for other document workflows: keep the source excerpt close to the value, identify missing information and preserve a correction when the user supplies one. If a value was calculated from other fields, show that calculation rather than presenting it as a quote from the document.

Source links make values easier to check. Measuring extraction accuracy still requires reviewed examples, including incomplete and difficult documents.
