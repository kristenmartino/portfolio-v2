A team might begin with a request to replace a billing tool because invoices keep needing corrections. I would first separate the observation from the proposed fix.

In that hypothetical case, the observation is repeated invoice corrections. Useful questions include which products are affected, where the incorrect values first appear and whether the issue is in configuration, source data or a manual handoff. Replacing the tool is one possible response, but the evidence may point to a smaller change.

I would collect a few representative cases, trace them through the workflow and compare explanations with the people doing the work. Then I would write down the options and what evidence would support each one.

This takes time and should fit the size of the decision. A small, reversible fix may need only a short check. A migration affecting several teams calls for a more detailed investigation.
