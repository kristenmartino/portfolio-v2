## What I built

FocusForge is an iPhone focus timer with character customization, cosmetic rewards and written prompts selected on the device. Completed sessions contribute to progression; streak milestones and earned coins unlock cosmetics.

## Sessions and rewards

A user starts a focus session, records its completion and sees the resulting progression. The character has configurable appearance and equipment slots. Cosmetics unlock through streak milestones or the app's coin economy.

The design goal is to make returning to a focus session appealing. Whether the rewards improve retention or encourage people to optimize for the reward system is a question for beta.

## Written prompts on the device

The coach selects from written templates using signals such as completion rate, session length and streak risk. It offers a prompt before a session, a reflection afterward or a reminder near a streak deadline. Users can edit, accept, dismiss or rate the prompt.

This is deterministic template selection. It does not run a language model or call a model API. Local prompt selection also does not mean that every part of the app is offline: Firebase is integrated for analytics, crash reporting and remote configuration.

## Interface and implementation

SwiftData stores local application records. SwiftUI provides the timer, character views, quests and statistics. The visual design separates a restrained focus screen from the more detailed reward presentation.

The reward overlay has a staged reveal, a skip action and a reduced-motion alternative. Contrast checks informed changes to text and rarity colors. VoiceOver, Dynamic Type, hit targets and motion preferences are part of the release review; these implementation measures do not establish complete accessibility conformance.

## What remains

Beta runtime checks, accessibility review and App Store submission remain. iPad layout and CloudKit sync were deferred so the initial release could concentrate on iPhone.

Beta evaluation should examine whether people return to the timer, how they use rewards and whether the prompts are useful. The privacy review also needs to confirm actual analytics payloads and opt-out behavior alongside the local prompt workflow.
