## What I built

Tarazu is a product-prioritization tool built around RICE: reach, impact, confidence and effort. Users can review AI-suggested inputs, change the values, compare product ideas and record the reasoning behind a ranking.

## Reviewing the inputs

I organized the workflow around the assumptions behind each score. Reach asks which user segment is affected. Impact asks what behavior might change. Confidence asks what evidence supports the estimate. Effort asks who supplied the estimate and how recent it is.

For a hypothetical initiative with an optimistic reach estimate, a reviewer can lower that input and see how the ranking responds.

## Keeping the calculation inspectable

The application displays the four inputs alongside the resulting score. AI-generated guidance is separate from the calculation, so a user can inspect the arithmetic and revise a suggestion.


## What I would test next

I would observe people comparing a small set of product ideas: can they find the assumptions behind a score, correct an estimate and explain why the ranking changed? A later review could compare the estimates with actual reach and effort.

The current web workflow also leaves room for better evidence capture and a compact export for planning discussions. Those are follow-up improvements; the existing score and generated guidance should be reviewed with the uncertainty of their inputs in mind.
